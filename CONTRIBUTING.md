# Contributing to Gleanary

Gleanary is **source-available**, not open contribution. It is a personal
project, developed to the author's own needs, and published under the
[PolyForm Noncommercial 1.0.0](LICENSE.md) license so others can self-host,
study, and modify it for noncommercial use.

## Pull requests are not accepted

Please don't open PRs — they will be closed without review. This keeps the
project's scope, licensing, and maintenance burden manageable for a single
maintainer.

If you want a change, you're welcome (and encouraged) to fork and adapt the
project for your own noncommercial use.

## What is welcome

- **Bug reports** — use the issue templates.
- **Security reports** — **do not open a public issue**; see
  [SECURITY.md](SECURITY.md) for private reporting.
- **Ideas and feedback** — feel free to open an issue. No promises, but it's
  useful to know what people run into.

## Developing your own fork

See [docs/development.md](docs/development.md) for setup, commands, and the
AI-assisted workflow this repo uses.
