The Build Log: Shipping a CLI in a Weekend

Hey there,

This weekend I finally shipped tidyup, a small command-line tool that finds and archives stale branches across every repository in a folder. It started as a twenty-line shell script and, as these things do, grew into a real project with tests, a config file, and opinions.

Three things surprised me:

  • Argument parsing is still the most annoying part of any CLI.
  • Colour output breaks on more terminals than you would expect.
  • People will immediately ask for a Windows build.

The code is on GitHub, and the install instructions are in the README. If you try it, reply and tell me what breaks.
