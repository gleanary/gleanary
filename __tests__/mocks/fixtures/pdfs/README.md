# PDF Test Fixtures

Binary PDF fixtures for `pdf-preflight` unit tests (page-count, encryption, metadata extraction).

## Files

| File                  | Purpose                                                      | Notes                                            |
| --------------------- | ------------------------------------------------------------ | ------------------------------------------------ |
| `minimal-text.pdf`    | 1-page PDF, no /Info metadata                                | Generated by `scripts/generate-pdf-fixtures.mjs` |
| `multi-page-text.pdf` | 3-page PDF                                                   | Generated by `scripts/generate-pdf-fixtures.mjs` |
| `low-quality.pdf`     | 1-page PDF (legacy; retained for any future quality tooling) | Generated by `scripts/generate-pdf-fixtures.mjs` |
| `corrupted.pdf`       | Valid magic bytes (`%PDF-`) but malformed body               | Generated by `scripts/generate-pdf-fixtures.mjs` |
| `encrypted.pdf`       | Password-protected PDF used to verify `EncryptedPdfError`    | Committed binary (see below for regeneration)    |

## Regenerating the encrypted fixture

To rebuild `encrypted.pdf`:

```bash
# Requires qpdf (brew install qpdf)
qpdf --encrypt "userpassword" "ownerpassword" 128 -- minimal-text.pdf encrypted.pdf
```

## Regeneration

Run the generation script to rebuild all files (except `encrypted.pdf`):

```bash
node scripts/generate-pdf-fixtures.mjs
```

Then commit the updated binary files.
